# 解答解説テンプレート → アプリ正式表示仕様 方針 v1.0

策定日: 2026-09-02

## 1. 正式方針

作成中の「解答解説テンプレート」そのものを、学習アプリの解答解説画面における上位仕様とする。

テンプレート完成後は、アプリ側の都合でテンプレート項目を削除・統合・名称変更しない。

設計の優先順位は次の通りとする。

`解答解説テンプレート → Excel正本 → Canonical Data → TypeScript型 → Zod Schema → IndexedDB/Dexie → 解答解説UI`

アプリSchemaはテンプレートを表現するために変更するものであり、テンプレートを現行Schemaへ無理に合わせない。

---

## 2. テンプレート完成前の扱い

テンプレートが完成・承認されるまでは、解答解説Schemaの最終固定を行わない。

現在のSchema 0.3に存在する単一の`explanation`フィールドは暫定互換フィールドとして扱う。

正式データ投入前に、完成したテンプレートの全項目を構造化フィールドへマッピングする。

---

## 3. 画面表示原則

テンプレートに存在する項目は、原則として解答解説画面で独立した表示ブロックとして表示できるようにする。

例:

- 解答
- この問題で問われていること
- 正解に至る考え方
- 各選択肢解説
- 関連する周辺知識
- 臨床現場での注意点
- 関連法規・ガイドライン
- 試験で覚える要点
- 覚え方
- 参考文献・根拠
- 図・画像・表

最終的な表示項目・名称・順序は、完成した解答解説テンプレートを正とする。

---

## 4. 選択肢解説

テンプレートで各選択肢に個別解説が存在する場合、選択肢単位で構造化して保持する。

想定項目:

- 正誤判定
- 正誤理由
- 誤答選択肢が正しくなる条件
- 正しい文への修正
- 鑑別・混同しやすい点
- 臨床上の注意点

テンプレート完成時に項目が追加・変更された場合は、テンプレートを優先する。

---

## 5. 図・画像・表

解答解説テンプレートに図・画像・表が含まれる場合、アプリでも表示できる構造とする。

媒体は本文文字列へ直接埋め込まず、MEDIAデータとして独立管理する。

想定メタデータ:

- media_id
- canonical_question_id
- placement
- display_order
- media_type
- file_name / blob reference
- caption
- alt_text
- source_id
- source_page
- revision

`placement`により、テンプレート内のどの項目の前後へ表示するかを指定できるようにする。

画像はIndexedDB/DexieへBlobとして保存できる設計とし、オフライン表示に対応する。

---

## 6. 空欄項目

テンプレート項目が特定問題で空欄の場合、アプリ画面では原則として空の見出しを表示しない。

必須項目と任意項目はテンプレート完成後に正式定義する。

表示順はテンプレートに従い、データが存在する任意ブロックのみ自動挿入する。

---

## 7. Excel正本との対応

正式Excel正本は、テンプレート項目を欠落なく保持できる構造とする。

既存の想定シート:

- QUESTIONS
- CHOICES
- EXPLANATIONS
- CHOICE_EXPLANATIONS
- SOURCES
- RELATIONS
- QA_LEDGER
- TAXONOMY
- MEDIA

ただし、テンプレート完成後に必要性が判明した場合は、シート・列を追加または再構成する。

Excelテンプレートの設計も、完成した解答解説テンプレートを確認した後に最終確定する。

---

## 8. QA要件

正式データ投入前に、各テンプレート項目について以下を検証する。

1. Excel正本に保存できる
2. 変換時に欠落しない
3. Zod validationを通過する
4. IndexedDBへ保存・復元できる
5. 解答解説画面に正しい順序で表示される
6. 空欄項目の扱いが正しい
7. 選択肢解説の対応先がずれない
8. 図・画像・表のplacementが正しい
9. バックアップ・復元後も欠落しない

1項目でも欠落する場合、正式問題データの一括投入へ進まない。

---

## 9. Version管理

解答解説テンプレート自体にもVersionを付与する。

例:

- Explanation Template Version: `1.0`
- Master Data Version: 別管理
- App Schema Version: 別管理
- App Version: 別管理

テンプレート項目の追加・削除・意味変更がある場合は、テンプレートVersionを更新し、必要に応じてSchema migrationを行う。

---

## 10. 次工程

1. 作成中の解答解説テンプレートを完成させる
2. 完成版をChatGPTへ提示する
3. 全項目・表示順・必須/任意・画像配置を監査する
4. テンプレートVersion 1.0を確定する
5. Excel正本列との対応表を作成する
6. TypeScript/Zod/Dexie Schemaを更新する
7. 解答解説UIを実装する
8. サンプル問題で表示QAを行う
9. 正式問題・解答解説データを投入する

本方針を、解答解説画面設計における上位決定事項とする。
