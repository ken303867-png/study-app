# Data Templates

正式データの**空テンプレートのみ**GitHubで管理します。

- `canonical-master-json-template.json`: Excel正本各sheetを表現するCanonical Master JSON Exportの空構造

正式問題本文を入力したExcel / Master JSON / Delivery JSONは `data/official/` または `data/private/` などGit管理対象外の場所で扱ってください。

Canonical Master JSON ExportとDelivery JSONはいずれも正本ではなく、正式Excel Master Dataから再生成可能な派生データとして扱います。
